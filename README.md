# technav

Tech room finder / navigation app (CS 392). Baseline from [criesbeck/react-start](https://github.com/criesbeck/react-start) (React, TypeScript, Vite, Tailwind, Vitest).

## Setup

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Typecheck and production build |
| `npm test` | Run Vitest (UI) |
